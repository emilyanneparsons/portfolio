# Emily Parsons — Portfolio

A small, static personal portfolio for [empars.com](https://empars.com), hosted
with GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run a local web server from this folder.

## Publish with GitHub Pages

1. Create a GitHub repository and push this project's `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.
5. In Squarespace Domains, add the DNS records GitHub lists for an apex custom
   domain.
6. Back in GitHub Pages settings, confirm `empars.com` as the custom domain and
   enable **Enforce HTTPS** after DNS finishes propagating.

The `CNAME` file already tells GitHub Pages to serve the site at `empars.com`.
